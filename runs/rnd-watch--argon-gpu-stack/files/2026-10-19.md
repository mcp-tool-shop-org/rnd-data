## 3. The studio's build recipe, for you to judge

- Source: Ollama 0.40.4 and its own llama.cpp pin (`b11521`).
- Preset `llama_cuda_v13_windows`, built with CUDA 13.4 Update 2 (nvcc V13.4.92).
- `CMAKE_CUDA_ARCHITECTURES=120a-real`
- `GGML_CUDA_FA_ALL_QUANTS=ON`
- `GGML_CUDA_COMPRESSION_MODE=speed`
- `GGML_CUDA_GRAPHS=ON`
- VMM on.
- cuBLAS / cuBLASLt from the same toolkit (13.4.3).
- MSVC runtime from the installed Ollama.
- Builds run capped: affinity 0x3FC (E-cores), below-normal priority, `-j 8`.
- Every activation goes through a sandbox test on port 11500 first.
- The studio build runs from its own tree. The installed stock CUDA 13.0 `cuda_v13` stays untouched as a switchable fallback (`USE_STOCK=1`).
